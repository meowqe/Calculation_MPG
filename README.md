# Linear Regression: Предсказание расхода топлива автомобилей (MPG)
## О проекте
---
Проект посвящен построению и анализу модели линейной регрессии для предсказания расхода топлива автомобилей (miles per gallon — mpg).
Цель проекта — понять, какие технические характеристики автомобиля наиболее сильно влияют на его топливную экономичность, а также оценить качество и интерпретируемость линейной модели.
В работе выполнен полный цикл анализа данных: от загрузки и исследовательского анализа (EDA) до предобработки, построения модели, оценки её качества и формулирования бизнес-выводов.
Структура проекта

---
1. Загрузка библиотек и данных
- Импорт необходимых библиотек
- Загрузка датасета mpg из seaborn

2. Первичный анализ (EDA)
- Изучение структуры данных
- Проверка типов данных, пропущенных значений и базовой статистики
- Анализ распределения целевой переменной mpg

3. Предобработка данных
- Удаление неинформативного признака name
- Обработка пропусков в столбце horsepower (удаление 6 строк)
- Проверка данных после очистки

4. Исследовательский анализ данных
- Анализ категориального признака cylinders
- Визуализация распределений числовых признаков
- Изучение взаимосвязей между признаками и целевой переменной mpg

5. Подготовка данных для моделирования
- Кодирование категориального признака origin (One-Hot Encoding)
- Разделение данных на обучающую и тестовую выборки

6. Построение и оценка модели
- Обучение модели Linear Regression
- Оценка качества модели (R², MAE, MSE, RMSE)
- Анализ коэффициентов модели (интерпретация влияния признаков)
- Визуализация предсказаний и ошибок модели (Residuals Plot, Prediction Error)

---
## Инструменты и библиотеки

Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, Yellowbrick
